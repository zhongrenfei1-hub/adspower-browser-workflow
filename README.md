# AdsPower 独立浏览器环境工作流

更新日期 2026-11-27

用于记录独立浏览器环境配置、邮箱验证和 Claude 账号初始化的人工辅助操作流程。

## 固定约定

- 每注册一个新账号，都新建一个独立 AdsPower 环境，分别保存 Cookie、缓存和登录会话。
- 参考已有环境的参数搭配，新环境使用独立生成的数据。
- 登录信息由用户在当次操作中提供。密码、验证码、辅助邮箱、会话 Cookie 和验证链接不得写入仓库或提交记录。
- 注册成功以进入账号聊天页面为准。

## 创建与检查环境

1. 查看参考环境的操作系统、内核、UA、网络和指纹概要。
2. 新建环境并设置清晰名称。选择 macOS 模拟配置和当前可用的较新浏览器内核。
3. 将 UA 的 Chrome 主版本与实际内核主版本保持一致。macOS 版本选项与 UA 中的系统字符串需分别核对。
4. 网络默认选择 No Proxy（本地直连），检查当前网络出口。电脑上的 VPN 或系统网络配置仍可能影响出口。
5. 时区、语言和地理位置按 IP 配置，地理位置每次询问，界面语言基于语言。
6. 分辨率基于 UA，字体默认。参考配置使用 WebRTC 禁用、Canvas 与 WebGL 图像真实值，AudioContext、媒体设备、ClientRects 和 SpeechVoices 启用噪音，WebGPU 基于 WebGL。
7. 检查 Apple 图形元数据、CPU、内存和设备名称的搭配。保存后启动并核对实际页面。

## 邮箱验证与注册

1. 在该新环境中打开 https://claude.ai/，输入用户指定邮箱。
2. 在同一环境的新标签页打开邮箱官网，使用当次提供的账号登录。
3. 遇到辅助邮箱确认时使用用户提供的信息。手机确认、短信或验证器动态码需要相应设备或可访问的验证渠道。
4. 读取 Anthropic 验证邮件并打开有效的登录链接，或按页面要求填写验证码。
5. 出现验证码时按当前工具规则取得必要确认，再处理当前挑战。
6. 到条款、使用政策与年龄确认步骤时，取得用户明确确认后提交。
7. 默认选择免费方案，跳过可选的桌面客户端下载、营销订阅和职业问卷。显示名称使用用户指定名称，未指定时可参考邮箱名称并在结果中说明。
8. 本次初始化关闭了用于改进 AI 模型的数据选项。后续操作依据用户偏好设置。
9. 确认进入聊天界面，并报告对应环境、方案和仍待处理的问题。

## 已验证的操作记录

本次在 Windows 主机的 AdsPower 中新建了 macOS 模拟环境，使用 Chrome 157 和匹配的 UA、本地直连，并成功完成邮箱验证、Claude 账号创建和免费方案初始化。

这是一份操作记录。具体版本、界面和验证要求应以执行时实际页面为准。一次注册成功无法保证后续风控结果，独立浏览器环境也仍会通过当前网络出口访问服务。

## 后续复用

执行前读取本文件，确认目标服务、用户指定邮箱和已有环境列表，然后为新账号创建新环境。遇到错误记录错误现象及已完成步骤，避免重复注册。
